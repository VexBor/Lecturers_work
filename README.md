🧾 Технічне завдання: Консольна програма «Курси навчання»
1. Мета програми

Розробити консольну програму, яка дозволяє користувачу:

переглядати доступні курси;

обирати курси для навчання;

бачити інформацію про викладачів та вартість;

розраховувати загальну суму оплати за обрані курси.


Програма відображає список доступних курсів.

Користувач може вибрати один або кілька курсів (через введення їх номерів).

Після вибору програма:

виводить деталі кожного курсу (назву, викладача, ціну);

обчислює підсумкову суму оплати;

показує загальну суму.

Програма завершується після підтвердження вибору.

6. Результат роботи програми

На виході користувач отримує:

Список обраних курсів з цінами;

Загальну суму оплати;

Інформаційне повідомлення про успішну "реєстрацію".
